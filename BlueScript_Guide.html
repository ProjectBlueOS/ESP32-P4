Overview

BlueScript is a BASIC-inspired scripting language designed for Project Blue on the ESP32-P4. Scripts are plain-text files with the .bb extension. They run in a managed windowed environment with 2D/3D graphics, mouse and keyboard input, networking, file I/O, audio, and remote peripheral control.

Event-Driven

Scripts respond to mouse, keyboard, and per-frame update events via labeled handlers.

Display List Rendering

Drawing commands are collected into a thread-safe display list and replayed each frame.

Dot-Namespaced API

All commands use a Namespace.Command convention for clarity and organization.

Quick Start

Create a file with the .bb extension and place it on the SD card or in the /scripts/ directory. The menu bar will detect it automatically.

# My First BlueScript
:onUpdate
SYSTEM.APPNAME "Hello World"
SYSTEM.GETTIME
RETURN

:onDraw
Graphics.FillRect 0, 0, win_w, win_h, BLACK
Graphics.DrawString 20, 20, "Hello, Project Blue!", WHITE
Graphics.DrawString 20, 50, hour + ":" + minute, CYAN
RETURN

Script Structure

A BlueScript program is organized into labels that define execution blocks. The runtime calls specific labels at specific times:

LabelWhen It Runs
:onUpdateEvery frame. Use for game logic, animation state, input processing.
:onDrawEvery frame, after onUpdate. Use for all drawing commands.
:onMouseEventWhen mouse events occur. Check event_type, event_x, event_y.
:onKeyboardEventWhen keyboard events occur. Check event_type, event_value.
:myLabelCustom labels for GOTO/GOSUB jumps.

Rules

  • Lines starting with # are comments.
  • Lines starting with : define labels.
  • All other lines are commands with arguments.
  • Every event handler must end with RETURN.
  • Blank lines are ignored.

Execution Flow

  1. The file is read line-by-line and tokenized.
  2. Labels are registered for jump targets.
  3. Code before any label runs once on the first frame (setup code).
  4. :onUpdate runs every frame for logic.
  5. :onDraw runs every frame for rendering.
  6. Event handlers run when input events are received.

Variables & Data Types

BlueScript supports three data types via the LET command:

TypeDescriptionExample
INTInteger numberLET score = 100
FLOATFloating-point numberLET pi = 3.14159
STRString (text)LET name = "Project Blue"
LET score = 0
LET pi = 3.14159
LET greeting = "Hello"
LET fullGreeting = greeting + " World"  # String concatenation with +
LET hexColor = 0xF800  # Hex literals supported

Type Promotion

  • If either operand is FLOAT, arithmetic uses float.
  • If either operand is STR, + concatenates strings.

Assignment Syntax

The LET command assigns a value. The = sign is the assignment operator (not a comparison):

LET x = 10
LET y = x * 2 + 5
LET label = "Score: " + score

Expressions

The expression evaluator is a recursive-descent parser with operator precedence.

Operators

OperatorDescriptionExample
+Addition / String concatenationa + b, "Hi " + name
-Subtraction / Unary minusa - b, -x
*Multiplicationa * b
/Divisiona / b
%Moduloa % 2
=, ==EqualIF x = 10 THEN ...
!=Not equalIF x != 0 THEN ...
>Greater thanIF x > 5 THEN ...
<Less thanIF x < 5 THEN ...
>=Greater or equalIF x >= 5 THEN ...
<=Less or equalIF x <= 5 THEN ...

Features

  • Parentheses for grouping: (a + b) * c
  • String literals enclosed in "..."
  • Hex literals with 0x prefix: 0xF800
  • Variable lookup by name
  • No AND/OR/NOT — use nested IF statements instead
Important: BlueScript has no boolean operators (AND, OR, NOT). To combine conditions, use nested IF statements or separate checks with GOTO labels.

Flow Control

IF / THEN / ELSE / ENDIF

IF score > 100 THEN Graphics.DrawString 10, 10, "High Score!", GREEN

IF health = 0 THEN
    Graphics.DrawString 10, 10, "Game Over", RED
ELSEIF health < 25 THEN
    Graphics.DrawString 10, 10, "Low Health", ORANGE
ELSE
    Graphics.DrawString 10, 10, "Healthy", GREEN
ENDIF

FOR / NEXT Loop

FOR i = 0 TO 10
    Graphics.FillCircle i * 30, 100, 5, WHITE
NEXT

# Countdown with STEP
FOR t = 60 TO 0 STEP -1
    PRINT t
NEXT

GOTO / GOSUB / RETURN

# GOTO - unconditional jump
:start
PRINT "Looping..."
GOTO start

# GOSUB - call a subroutine (returns with RETURN)
GOSUB drawBorder
GOSUB drawHUD
RETURN

:drawBorder
Graphics.DrawRect 0, 0, win_w, win_h, WHITE
RETURN

:drawHUD
Graphics.DrawString 10, 10, "HP: " + health, GREEN
RETURN

END

IF quit = 1 THEN END

Event Handlers

Mouse Events

:onMouseEvent
IF event_type = "Down" THEN
    LET clickX = event_x
    LET clickY = event_y
    LET clicked = 1
ENDIF
IF event_type = "Move" THEN
    LET mouseX = event_x
    LET mouseY = event_y
ENDIF
RETURN

Event variables:

VariableValues
event_type"Down", "Up", "Move"
event_xMouse X coordinate (relative to window content)
event_yMouse Y coordinate (relative to window content)

Keyboard Events

:onKeyboardEvent
IF event_type = "KeyDown" THEN
    IF event_value = "Escape" THEN System.Close
    IF event_value = "Space" THEN LET jumping = 1
ENDIF
IF event_type = "Char" THEN
    LET lastKey = event_value
ENDIF
RETURN

Event variables:

VariableValues
event_type"KeyDown", "KeyUp", "Char"
event_valueKey name, e.g. "Escape", "Space", "a", "Enter"

Interactive Button with Collision

LET pressCount = 0
LET btnX = 10
LET btnY = 200
LET btnW = 150
LET btnH = 50
LET btnPressed = 0

:onMouseEvent
Collision.PointRect event_x,event_y, btnX,btnY,btnW,btnH
IF collision_hit = 1 THEN
    IF event_type = "Down" THEN
        LET btnPressed = 1
        LET pressCount = pressCount + 1
    ENDIF
    IF event_type = "Up" THEN
        LET btnPressed = 0
    ENDIF
ENDIF
RETURN

:onDraw
Graphics.FillRect 0, 0, win_w, win_h, BLACK
Graphics.DrawButton btnX,btnY,btnW,btnH, "Click Me", btnPressed
Graphics.DrawString 10, 10, "Clicks: " + pressCount, WHITE
RETURN

Animated Particle System

LET t = 0

:onUpdate
LET t = t + delta_time
RETURN

:onDraw
Graphics.FillRect 0, 0, win_w, win_h, BLACK
FOR i = 0 TO 5
    LET angle = t * 60 + i * 60
    Math.Sin angle
    LET px = 400 + result * 150
    Math.Cos angle
    LET py = 300 + result * 150
    Graphics.FillCircle px, py, 8, CYAN
    Graphics.FillCircle px, py, 4, WHITE
NEXT
RETURN

Keyboard-Controlled Movement

LET px = 400
LET py = 300
LET speed = 200

:onUpdate
SYSTEM.APPNAME "Keyboard Control"
RETURN

:onKeyboardEvent
IF event_type = "KeyDown" THEN
    IF event_value = "ArrowLeft" THEN LET px = px - speed * delta_time
    IF event_value = "ArrowRight" THEN LET px = px + speed * delta_time
    IF event_value = "ArrowUp" THEN LET py = py - speed * delta_time
    IF event_value = "ArrowDown" THEN LET py = py + speed * delta_time
    IF event_value = "Escape" THEN System.Close
ENDIF
RETURN

:onDraw
Graphics.FillRect 0, 0, win_w, win_h, BLACK
Graphics.FillCircle px, py, 16, CYAN
Graphics.DrawString 10, 10, "Arrow keys to move", GRAY
RETURN
