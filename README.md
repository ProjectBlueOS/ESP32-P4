Welcome to the Project Blue GitHub Repo for the ESP32-P4 
This is Version 1.0 Alpha release of the bare metal windowing OS desktop for the ESP32-P4
This is the Serial Version (not Ethernet/networking version)

Instructions:
-------------
Flash your ESP32-p4 board with the .bin file in this repo
Connect a Serial cable from the board to your laptop/computer
Use the Project Blue Contral Viewer Client Viewer html file to select the serial port of the board
Interact the the programs and Games using your keyboard and mouse - the Desktop OS is running on the Board

create a folder by the name of 'script' in the root of your SD card on the ESP32-P4 and copy the sample .bb files to it - Project Blue OS will list them in the MenuBar for you to select and execute

Note: This is V1.0 Alpha release so the Browser and Email client are not yet functional but everything else is working
Try it out - have fun and let me know if any issues - if I am still around I will upload the updated binaries
